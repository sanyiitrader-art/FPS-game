# Assets and licenses

Every third-party file in the game must come from a source that allows use and
redistribution inside a game, including commercial use. This file is the record.
The build checks that every asset pack is listed here with an approved license.

## Rules

1. **One folder per pack.** Put each download in its own folder:

   - `assets/models/characters/<pack>/...`, `assets/models/weapons/<pack>/...`,
     `assets/models/props/<pack>/...`
   - `assets/audio/music/<pack>/...`, `assets/audio/sfx/<pack>/...`,
     `assets/audio/ambient/<pack>/...`
   - `assets/textures/<pack>/...`
   - `assets/ui/<pack>/...`

   Use short lowercase names with underscores, for example `quaternius_soldiers`.
2. **Add a row to the ledger below** before building. The pack folder name must appear in
   the row.
3. **Approved licenses:** CC0, CC-BY (credit required, see Credits), MIT, Apache 2.0,
   OFL (fonts), Public Domain, or your own work.
4. **Not allowed:** anything marked NonCommercial (NC) or NoDerivatives (ND), content ripped
   from other games, and anything whose license you cannot find or read.
5. **Do not assume a free download is redistributable.** Read the license on the
   download page and copy its name and link here.
6. Keep textures small and reuse files. Do not add models or sounds the game does not use.

## Files generated by the build

`assets/generated/` is created on every build (launcher icons from `icon.png`, placeholder
images). Do not edit or commit it.

Real artwork replaces placeholders by name, for example `assets/ui/map_urban.png`
replaces `map_urban_placeholder.png`.
